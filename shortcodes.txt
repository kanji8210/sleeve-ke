===============================================
SLEEVE KE - WORDPRESS PLUGIN SHORTCODES
===============================================
All available shortcodes with detailed usage instructions and examples.

===============================================
1. EMPLOYER REGISTRATION FORM
===============================================
Shortcode: [sleeve_ke_employer_registration]

Description:
Displays a complete employer registration form on any page or post. This form allows 
companies to create an employer account with full profile information.

Features:
- User account creation (username, email, password)
- Company information (name, logo upload, description, website)
- Contact details (phone, location)
- Business details (industry, company size)
- Automatic role assignment (employer)
- Profile photo upload support
- Terms and conditions acceptance

Usage:
Simply add the shortcode to any page where you want the employer registration form:
[sleeve_ke_employer_registration]

Parameters: None

Example:
Create a page called "Register as Employer" and add:
[sleeve_ke_employer_registration]

Notes:
- Form automatically redirects to employer dashboard upon successful registration
- All fields are validated before submission
- Company logo is stored in WordPress media library
- Creates entries in wp_users and wp_sleeve_employers tables


===============================================
2. CANDIDATE REGISTRATION FORM
===============================================
Shortcode: [sleeve_ke_candidate_registration]

Description:
Displays a complete candidate registration form allowing job seekers to create their 
profile and start applying for jobs.

Features:
- User account creation (username, email, password)
- Personal information (first name, last name, phone, location)
- Professional details (experience level, education, skills)
- Career preferences (desired industry, job alerts)
- Email notification settings
- Bio/introduction section
- Privacy settings

Usage:
Add the shortcode to any page where you want the candidate registration form:
[sleeve_ke_candidate_registration]

Parameters: None

Experience Levels Available:
- Entry Level (0 years)
- Junior (2 years)
- Mid-Level (5 years)
- Senior (10 years)
- Expert (15+ years)

Example:
Create a page called "Register as Candidate" and add:
[sleeve_ke_candidate_registration]

Notes:
- Form redirects to same page with success message after registration
- Creates entries in wp_users and wp_sleeve_candidates tables
- Automatic role assignment (candidate)
- Phone validation accepts international formats
- Skills stored as comma-separated text


===============================================
3. EMPLOYER PROFILE MANAGEMENT
===============================================
Shortcode: [sleeve_ke_employer_profile]

Description:
Displays the employer profile management interface where employers can view and 
edit their company information, manage jobs, and view applications.

Features:
- View and edit company profile
- Update company logo
- Manage company description and details
- Update contact information
- Change business information (industry, size)
- Quick access to job management
- Application tracking

Usage:
Add to employer dashboard page:
[sleeve_ke_employer_profile]

Parameters: None

Access Control:
- Only visible to logged-in users with 'employer' role
- Non-employers see access denied message

Example:
Create a page called "My Profile" (slug: employer-profile) and add:
[sleeve_ke_employer_profile]

Notes:
- Requires user to be logged in
- Automatically loads current employer's data
- Changes are saved to wp_sleeve_employers table
- Logo upload replaces previous logo


===============================================
4. JOB LISTING DISPLAY
===============================================
Shortcode: [sleeve_ke_jobs]

Description:
Displays a filterable, searchable job listing with advanced options for layout 
customization and filtering capabilities.

Features:
- Grid or list layout
- Advanced search functionality
- Multiple filter options (job type, location, salary range)
- Pagination support
- Company logo display
- Salary information
- Posted date
- Job type badges
- Save/bookmark jobs (for logged-in candidates)
- Responsive design

Usage:
Basic usage:
[sleeve_ke_jobs]

With custom parameters:
[sleeve_ke_jobs columns="3" posts_per_page="21" layout="grid" show_filters="true"]

Available Parameters:

columns (default: "3")
  - Number of columns in grid layout
  - Values: 1, 2, 3, or 4
  - Example: columns="4"

posts_per_page (default: "21")
  - Number of jobs to display per page
  - Values: 1-50
  - Example: posts_per_page="12"

show_filters (default: "true")
  - Display filter sidebar
  - Values: "true" or "false"
  - Example: show_filters="false"

show_search (default: "true")
  - Display search bar
  - Values: "true" or "false"
  - Example: show_search="true"

show_pagination (default: "true")
  - Display pagination controls
  - Values: "true" or "false"
  - Example: show_pagination="false"

job_type (default: "")
  - Pre-filter by job type
  - Values: "full_time", "part_time", "contract", "freelance", "internship"
  - Example: job_type="full_time"

location (default: "")
  - Pre-filter by location
  - Example: location="Nairobi"

category (default: "")
  - Pre-filter by category/industry
  - Example: category="technology"

featured_only (default: "false")
  - Show only featured jobs
  - Values: "true" or "false"
  - Example: featured_only="true"

layout (default: "grid")
  - Display layout style
  - Values: "grid" or "list"
  - Example: layout="list"

show_company_logo (default: "true")
  - Display company logos
  - Values: "true" or "false"
  - Example: show_company_logo="false"

show_salary (default: "true")
  - Display salary information
  - Values: "true" or "false"
  - Example: show_salary="true"

show_date (default: "true")
  - Display posted date
  - Values: "true" or "false"
  - Example: show_date="false"

orderby (default: "date")
  - Sort jobs by field
  - Values: "date", "title", "modified", "rand"
  - Example: orderby="title"

order (default: "DESC")
  - Sort order
  - Values: "ASC" or "DESC"
  - Example: order="ASC"


USAGE EXAMPLES:

Simple job board page:
[sleeve_ke_jobs]

Compact list view with 10 jobs:
[sleeve_ke_jobs layout="list" posts_per_page="10"]

4-column grid without filters:
[sleeve_ke_jobs columns="4" show_filters="false"]

Featured jobs only, 2 columns:
[sleeve_ke_jobs featured_only="true" columns="2"]

Full-time jobs in Nairobi:
[sleeve_ke_jobs job_type="full_time" location="Nairobi"]

Search only (no filters), sorted by title:
[sleeve_ke_jobs show_filters="false" orderby="title" order="ASC"]

Minimal job list (no logos, no salary, no date):
[sleeve_ke_jobs show_company_logo="false" show_salary="false" show_date="false"]


Filter Options Available:
- Job Type: Full-time, Part-time, Contract, Freelance, Internship
- Location: All registered locations
- Salary Range: Custom min/max range
- Experience Level: Entry, Junior, Mid-level, Senior, Expert
- Remote Work: On-site, Hybrid, Remote
- Industry/Sector: All industries from employers


Notes:
- Uses AJAX for filtering without page reload
- Mobile responsive
- Integrates with candidate save/bookmark system
- Shows job count in real-time
- Expired jobs automatically hidden

ADDITIONAL INFORMATION
===============================================

Page Creation Recommendations:

1. Create "Register as Employer" page:
   - Slug: employer-registration
   - Content: [sleeve_ke_employer_registration]
   - Template: Full Width

2. Create "Register as Candidate" page:
   - Slug: candidate-registration
   - Content: [sleeve_ke_candidate_registration]
   - Template: Full Width

3. Create "Employer Dashboard" page:
   - Slug: employer-profile
   - Content: [sleeve_ke_employer_profile]
   - Template: Full Width
   - Set as private or require login

4. Create "Browse Jobs" page:
   - Slug: jobs
   - Content: [sleeve_ke_jobs]
   - Template: Full Width

5. Create "Featured Jobs" page:
   - Slug: featured-jobs
   - Content: [sleeve_ke_jobs featured_only="true" columns="3"]

6. Create "Remote Jobs" page:
   - Slug: remote-jobs
   - Content: [sleeve_ke_jobs remote_work="remote"]


Menu Integration:
Add these pages to your WordPress menu for easy navigation:
- Jobs (Browse all jobs)
- Register as Employer
- Register as Candidate
- Employer Dashboard (visible only to employers)


Styling:
All shortcodes use CSS classes prefixed with 'sleeve-ke-' for easy customization.
Main container classes:
- .sleeve-ke-registration-form
- .sleeve-ke-employer-profile
- .sleeve-ke-jobs-container

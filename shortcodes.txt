===============================================
1. EMPLOYER REGISTRATION FORM
===============================================
Shortcode: [sleeve_ke_employer_registration]

Description:
Displays a complete employer registration form on any page or post. This form allows 
companies to create an employer account with full profile information.

Features:
- User account creation (username, email, password)
- Company information (name, logo upload, description, website)
- Contact details (phone, location)
- Business details (industry, company size)
- Automatic role assignment (employer)
- Profile photo upload support
- Terms and conditions acceptance

Usage:
Simply add the shortcode to any page where you want the employer registration form:
[sleeve_ke_employer_registration]

Parameters: None

Example:
Create a page called "Register as Employer" and add:
[sleeve_ke_employer_registration]

Notes:
- Form automatically redirects to employer dashboard upon successful registration
- All fields are validated before submission
- Company logo is stored in WordPress media library
- Creates entries in wp_users and wp_sleeve_employers tables

2. CANDIDATE REGISTRATION FORM
===============================================
Shortcode: [sleeve_ke_candidate_registration]

Description:
Displays a complete candidate registration form allowing job seekers to create their 
profile and start applying for jobs.

Features:
- User account creation (username, email, password)
- Personal information (first name, last name, phone, location)

- Privacy settings

Usage:
Add the shortcode to any page where you want the candidate registration form:
[sleeve_ke_candidate_registration]

Parameters: None

Experience Levels Available:
- Entry Level (0 years)
- Junior (2 years)
- Mid-Level (5 years)
- Senior (10 years)
- Expert (15+ years)

Example:
Create a page called "Register as Candidate" and add:
[sleeve_ke_candidate_registration]

Notes:
- Form redirects to same page with success message after registration
- Creates entries in wp_users and wp_sleeve_candidates tables
- Automatic role assignment (candidate)
- Phone validation accepts international formats

4. JOB LISTING DISPLAY
===============================================
Shortcode: [sleeve_ke_jobs]

Description:
Displays a filterable, searchable job listing with advanced options for layout 
customization and filtering capabilities.

Features:
- Grid or list layout
- Advanced search functionality
- Multiple filter options (job type, location, salary range)
- Pagination support
- Company logo display
- Salary information
- Posted date
- Job type badges
- Save/bookmark jobs (for logged-in candidates)
- Responsive design

Usage:
Basic usage:
[sleeve_ke_jobs]

With custom parameters:
[sleeve_ke_jobs columns="3" posts_per_page="21" layout="grid" show_filters="true"]

Available Parameters:

columns (default: "3")
  - Number of columns in grid layout
  - Values: 1, 2, 3, or 4
  - Example: columns="4"

posts_per_page (default: "21")
  - Number of jobs to display per page
  - Values: 1-50
  - Example: posts_per_page="12"

show_filters (default: "true")
  - Display filter sidebar
  - Values: "true" or "false"
  - Example: show_filters="false"

show_search (default: "true")
  - Display search bar
  - Values: "true" or "false"
  - Example: show_search="true"

show_pagination (default: "true")
  - Display pagination controls
  - Values: "true" or "false"
  - Example: show_pagination="false"

job_type (default: "")
  - Pre-filter by job type
  - Values: "full_time", "part_time", "contract", "freelance", "internship"
  - Example: job_type="full_time"

location (default: "")
  - Pre-filter by location
  - Example: location="Nairobi"

category (default: "")
  - Pre-filter by category/industry
  - Example: category="technology"

featured_only (default: "false")
  - Show only featured jobs
  - Values: "true" or "false"
  - Example: featured_only="true"

layout (default: "grid")
  - Display layout style
  - Values: "grid" or "list"
  - Example: layout="list"

show_company_logo (default: "true")
  - Display company logos
  - Values: "true" or "false"
  - Example: show_company_logo="false"

show_salary (default: "true")
  - Display salary information
  - Values: "true" or "false"
  - Example: show_salary="true"

show_date (default: "true")
  - Display posted date
  - Values: "true" or "false"
  - Example: show_date="false"

orderby (default: "date")
  - Sort jobs by field
  - Values: "date", "title", "modified", "rand"
  - Example: orderby="title"

order (default: "DESC")
  - Sort order
  - Values: "ASC" or "DESC"
  - Example: order="ASC"


USAGE EXAMPLES:

Simple job board page:
[sleeve_ke_jobs]

Compact list view with 10 jobs:
[sleeve_ke_jobs layout="list" posts_per_page="10"]

4-column grid without filters:
[sleeve_ke_jobs columns="4" show_filters="false"]

Featured jobs only, 2 columns:
[sleeve_ke_jobs featured_only="true" columns="2"]

Full-time jobs in Nairobi:
[sleeve_ke_jobs job_type="full_time" location="Nairobi"]

Search only (no filters), sorted by title:
[sleeve_ke_jobs show_filters="false" orderby="title" order="ASC"]

Minimal job list (no logos, no salary, no date):
[sleeve_ke_jobs show_company_logo="false" show_salary="false" show_date="false"]


Filter Options Available:
- Job Type: Full-time, Part-time, Contract, Freelance, Internship
- Location: All registered locations
- Salary Range: Custom min/max range
- Experience Level: Entry, Junior, Mid-level, Senior, Expert
- Remote Work: On-site, Hybrid, Remote
- Industry/Sector: All industries from employers


Notes:
- Uses AJAX for filtering without page reload
- Mobile responsive
- Integrates with candidate save/bookmark system
- Shows job count in real-time
- Expired jobs automatically hidden

5. EMPLOYER APPLICATIONS MANAGEMENT
===============================================
Shortcode: [sleeve_ke_employer_applications]

Description:
Displays a complete application management dashboard for employers to review 
and manage job applications submitted to their job postings. Employers can 
schedule interviews and update application statuses without direct candidate 
contact information.

Features:
- View all applications to employer's jobs
- Application statistics dashboard (Total, Pending, Interview, Accepted)
- Filter by job position, status, or search candidates
- View detailed candidate profiles (experience, education, skills)
- Download candidate resumes
- View cover letters
- Schedule interviews with date/time and location
- Update application status (Pending, Reviewed, Interview, Accepted, Rejected)
- Internal notes system
- No direct candidate contact (email/phone hidden)

Usage:
Add to employer applications page:
[sleeve_ke_employer_applications]

Parameters: None

Access Control:
- Only visible to logged-in users with 'employer' role
- Non-employers see access denied message
- Employers only see applications to their own jobs

Application Statuses:
- Pending: New application awaiting review
- Reviewed: Application has been reviewed
- Interview: Interview scheduled with candidate
- Accepted: Candidate accepted for position
- Rejected: Application declined

Actions Available:
1. View Details: Opens modal with full candidate information
2. Schedule Interview: Set date, location/method (Zoom, Office, etc.)
3. Mark as Reviewed: Change status to reviewed
4. Accept Application: Accept the candidate
5. Reject Application: Decline the application

Example:
Create a page called "My Applications" (slug: employer-applications) and add:


Notes:
- Requires user to be logged in as employer
- Applications are automatically filtered by employer's jobs
- Interview notifications sent to candidates (system handles communication)
- Candidate contact information is not displayed to maintain privacy
- Resume download available for all applications
- Responsive design for mobile access
- AJAX-powered for smooth user experience

6. UNIVERSAL DASHBOARD
===============================================
Shortcode: [sleeve_ke_dashboard]

Description:
Displays a role-based dashboard that automatically adapts to the logged-in user's 
role (employer, candidate, or admin). Provides quick access to key features and 
statistics relevant to each user type.

Features:
- Automatic role detection and appropriate dashboard display
- Login prompt for non-logged-in users with registration links
- Role-specific statistics and metrics
- Quick action buttons for common tasks
- Recent activity display
- Profile completion indicator (candidates)
- Responsive design

EMPLOYER DASHBOARD FEATURES:
- Statistics: Total Jobs, Active Jobs, Applications, Pending Review
- Quick Actions: Post New Job, Manage Jobs, View Applications, Edit Profile
- Recent Applications table with candidate names, positions, dates, status
- Company name display

CANDIDATE DASHBOARD FEATURES:
- Profile completion progress bar with percentage
- Statistics: Total Applications, Pending, Interviews, Saved Jobs
- Quick Actions: Browse Jobs, My Applications, Saved Jobs, Edit Profile
- Recent Applications table with job titles, companies, dates, status

ADMIN DASHBOARD FEATURES:
- Quick Actions: Manage Jobs, Manage Candidates, Manage Employers, Manage Applications
- Direct links to all admin management pages

Usage:
Create a "Dashboard" or "My Account" page and add:
[sleeve_ke_dashboard]

Parameters: None

Access Control:
- Shows login prompt if user not logged in
- Automatically detects user role (employer/candidate/admin)
- Displays appropriate dashboard based on role
- Access denied message for users without proper roles

Examples:

1. Create main dashboard page:
   Page title: "Dashboard"
   Slug: dashboard
   Content: [sleeve_ke_dashboard]
   Template: Full Width

2. Create "My Account" page:
   Page title: "My Account"
   Slug: my-account
   Content: [sleeve_ke_dashboard]

3. Set as redirect after login:
   Use redirect_to parameter in login forms to send users to dashboard page

Notes:
- Single shortcode works for all user types
- No configuration needed - automatically adapts
- Shows registration links for non-logged-in visitors
- Statistics are live from database
- Recent items limited to 5 for quick overview
- "View All" links go to full management pages
- Profile completion encourages candidates to add more info
- Fully responsive for mobile devices

- Jobs (Browse all jobs)
- Register as Employer
